# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's security advisories:
<https://github.com/thekindofme/margin/security/advisories/new>

Don't open a public issue for a vulnerability. Include what you found, how to reproduce it and the Margin version. You can expect an acknowledgement within a few days. Fixes are released as soon as practical and credited to you if you wish.

## Scope

Margin is local-first: audio, transcripts and notes stay on your Mac. Of particular interest are issues that could leak that data, run unintended code (including through the updater, the `margin` command or its MCP server) or bypass the macOS permissions Margin relies on.

## Supported versions

Only the latest release receives security fixes.
